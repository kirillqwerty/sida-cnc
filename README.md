# SIDA Беларусь

Обычный многостраничный HTML-сайт: 15 самостоятельных страниц, включая каталог из восьми направлений. Конкретных модельных страниц нет: каждый тип оборудования представлен отдельной явной HTML-страницей. Весь контент, меню, карточки, изображения и формы записаны прямо в HTML. Генератора страниц и JavaScript-шаблонов нет.

## Структура

```text
public/                         ← исходники сайта; редактировать здесь
  index.html                    ← главная
  about/index.html              ← о компании
  contacts/index.html           ← контакты
  privacy/index.html            ← политика
  404.html                      ← страница ошибки
  catalog/
    index.html                  ← полный каталог
    5-axis/index.html           ← категория пятиосевых станков
    vertical-machining/         ← вертикальные обрабатывающие центры
    cnc-lathes/                  ← токарные станки
    gantry/                     ← портальные центры
    vertical-lathes/            ← вертикальные токарные станки
    horizontal-machining/       ← горизонтально-фрезерные центры
    grinding/                   ← шлифовальные станки
    special-tools/              ← специальный режущий инструмент
  do-not-press/index.html       ← страница красной кнопки
  assets/
    styles.css                  ← общие стили
    site.js                     ← только интерактивность
    images/                     ← логотип и фотографии
    video/                      ← фоновое видео и заставка
  robots.txt
  sitemap.xml
server/server.js                ← локальный сервер и обработка заявок
scripts/build.js                ← только копирование public в dist
scripts/check.js                ← проверка HTML и локальных ссылок
```

## Как редактировать и просматривать

Откройте `public/index.html` напрямую в браузере. Ссылки между страницами, CSS, логотип и фотографии используют относительные пути и работают без сборки. Тексты и разметку редактируйте непосредственно в нужном HTML-файле. Шапка и подвал явно записаны на каждой странице: общие изменения нужно вносить на всех страницах.

Для локального сервера и отправки заявок:

```bash
npm install
npm start
```

По умолчанию адрес — `http://localhost:4174`. При занятом порте в PowerShell: `$env:PORT='4174'; npm start`.

Сервер отдаёт `public` напрямую. Сборка для просмотра и редактирования не нужна: сохраните HTML или CSS и обновите страницу.

JavaScript только открывает мобильное меню и отправляет форму без перезагрузки. Весь контент и навигация доступны без него, а фоновое видео запускается средствами HTML. Формы имеют обычный method="post" и action: без JavaScript сервер возвращает результат обработки в JSON. При открытии с диска отправка заявок недоступна — нужен сервер.

## Проверка и размещение

```bash
npm run check
npm run build
```

`check` проверяет исходные HTML-страницы и ссылки на локальные файлы. `build` только копирует готовую папку `public` в `dist`, не создавая и не изменяя HTML. Для обычного статического хостинга можно загрузить содержимое `public` напрямую. Обработчик заявок требует отдельного Node.js-сервера и настроенных каналов доставки.

## Фотографии и видео

В каталоге используются представительские фотографии направлений: five-axis-center.jpg, vertical-machining.jpg, horizontal-machining-clean.png, turning-center.jpg, gantry-center.jpg. Фотографии special-profile-cutters.jpg и special-form-cutters.jpg используются в разделе специального режущего инструмента.

Логотип: `public/assets/images/sida-logo.png`. Видео: `public/assets/video/sida-production.mp4` — H.264, 1920×1072, 25 кадров/с, без звука, около 1,27 МБ. WebM не требуется. Заставка: `sida-production-poster.jpg`. При ограничении анимации или экономии трафика автоматическое воспроизведение отключено.

## Настройка заявок

Создайте `.env` на основе `.env.example`. Для email укажите `RESEND_API_KEY`, подтверждённый адрес `MAIL_FROM` и получателя `MAIL_TO`. Для Telegram нужны `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. При отсутствии этих параметров сервер сообщает, что каналы доставки не настроены.

Секреты хранятся только на сервере. Сервер проверяет поля и ограничивает частоту запросов.

Перед публичным запуском замените демонстрационные контакты, утвердите политику, добавьте подтверждённые характеристики и замените `example.by` непосредственно в `public/sitemap.xml`.
